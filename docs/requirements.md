# Requirements

## 1. Functional Requirements

**FR1 – Record Income**

The system shall allow users to add income transactions by entering the amount, description, category and date.

**FR2 – Record Expenses**

The system shall allow users to add expense transactions by entering the amount, description, category and date.

**FR3 – Manage Transactions**

The system shall allow users to edit and delete existing income and expense transactions.

**FR4 – Categorise Transactions**

The system shall allow users to assign categories to income and expense transactions to organise their financial records.

**FR5 – View Financial Summary**

The system shall calculate and display the total income, total expenses and remaining balance based on recorded transactions.

## 2. Non-Functional Requirements

**NFR1 – Performance**

The system shall display the financial summary within 3 seconds when processing up to 1,000 recorded transactions under normal operating conditions.

**NFR2 – Usability**

The system shall allow users to complete the process of adding a new income or expense transaction within 2 minutes.

**NFR3 – Data Persistence**

The system shall retain all saved transaction records after the application is closed and reopened.
