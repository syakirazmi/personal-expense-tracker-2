# Requirements

## Functional requirements

1. The system shall allow users to add income transactions by entering the amount, description, category and date.
2. The system shall allow users to add expense transactions by entering the amount, description, category and date.
3. The system shall allow users to edit and delete existing income and expense transactions.
4. The system shall allow users to assign categories to income and expense transactions to organise their financial records.
5. The system shall calculate and display the total income, total expenses and remaining balance based on recorded transactions.

## Non-functional requirements

1. The system shall display the financial summary within 3 seconds when processing up to 100 recorded transactions under normal operating conditions.
2. The system shall allow users to complete the process of adding a new income or expense transaction within 2 minutes.
3. The system shall retain all saved transaction records after the application is closed and reopened.
