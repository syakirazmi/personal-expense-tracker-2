# User Stories
1. As a user, I want to record my income transactions, so that I can keep track of the money I receive.
2. As a user, I want to record and categorise my expenses, so that I can monitor where my money is being spent.
3. As a user, I want to view my total income, total expenses and remaining balance. This is to ensure that I can understand my current financial situation and manage my spending effectively.
